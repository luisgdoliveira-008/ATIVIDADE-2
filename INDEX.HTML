ENTENDA O QUE É HTML

HTML (HyperText Markup Language) é a linguagem padrão para criar páginas da web, utilizado para estruturar e organizar o conteúdo de páginas, como textos, imagens, vídeos e links. Não é uma linguagem de programação, mas sim de marcação que define a estrutura de documentos usando tags para navegadores.

Em resumo, o HTML é a "espinha dorsal" de um site, fornecendo a estrutura sobre a qual o CSS (estilo) e o JavaScript (interatividade) são aplicados.

10 tags de um documento HTML

1. <h1 a h6>:Define títulos e subtítulos, estabelecendo a hierarquia do conteúdo.

exemplo de código: <h1>Título principal</h1>

TITULO PRINCIPAL



2. <p>: Define um parágrafo de texto.

exemplo de código: <p>Este é um parágrafo.</p>

Este é um parágrafo.



3. <a>: Define um link para outra página ou recurso.

exemplo de código: <a href="https://www.exemplo.com">Clique aqui</a>

Clique aqui

4. <img>: Define uma imagem.

exemplo de código: <img src="imagem.jpg" alt="Descrição da imagem">

5. <div>: Define uma divisão ou seção de um documento, usada para agrupar elementos e aplicar estilos.

exemplo de código: <div class="container">Conteúdo aqui</div>

Conteúdo aqui

6. <span>: Define um trecho de texto ou um elemento em linha, usado para aplicar estilos específicos.

exemplo de código: <span class="highlight">Texto destacado</span>

Texto destacado

7. <ul> e <ol>: Define listas não ordenadas e ordenadas, respectivamente.

exemplo de código: <ul><li>Item 1</li><li>Item 2</li></ul>

  • Item 1
  • Item 2

8. <table>: Define uma tabela para organizar dados em linhas e colunas.

exemplo de código: <table><tr><td>Célula 1</td><td>Célula 2</td></tr></table>

Célula 1Célula 2

9. <form>: Define um formulário para coletar dados do usuário.

exemplo de código: <form><input type="text" name="nome"></form>
